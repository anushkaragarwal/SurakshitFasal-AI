# 🌾 Surakshit Fasal AI

An AI-powered smart crop advisory platform that helps farmers identify crop diseases, receive safe pesticide recommendations, and get weather-aware farming guidance in regional languages. It also provides inspectors with a dashboard to monitor high-risk areas and improve agricultural safety.

---

# 🚨 Problem Statement

Farmers often struggle to identify crop diseases correctly and end up using incorrect or excessive pesticides. This leads to:

- Reduced crop yield
- Health risks due to pesticide misuse
- Environmental pollution
- Lack of access to expert agricultural guidance
- Difficulty understanding advisories because of language barriers

Agricultural inspectors also lack a centralized system to monitor disease outbreaks and identify high-risk regions efficiently.

---

# 💡 Solution

Surakshit Fasal AI uses AI-based image analysis to detect crop diseases from leaf images and provides:

- Disease identification
- Confidence score
- Severity assessment
- Safe pesticide recommendations
- Dosage instructions
- Precautions
- Harvest waiting period
- Weather-based farming advice
- PDF report generation
- Farmer and Inspector dashboards
